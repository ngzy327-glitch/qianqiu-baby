# 知识库目录说明

bot 启动后会扫描本目录下所有 `*.md` 的**文件头 TRIGGER 注释**, 建立"场景关键词 → 知识文件"索引(每10分钟重建),
命中用户消息关键词时**自动注入上下文**, 无需改代码。

## 文件格式(照抄即可)
```markdown
<!-- TRIGGER: 渗透|红队|漏洞|打点|payload|利用 -->
# 我的知识文件标题

正文(Markdown)…
```
- `TRIGGER:` 后面写关键词, 用 `|` 分隔; 不加这行 = 永远不会被检索到
- 建议一个文件讲一个主题, 关键词写"用户会怎么问"而不是文件内容

## 目录约定
| 目录 | 放什么 |
|---|---|
| `self_learned/` | 机器人自己沉淀的学习笔记(自动写入) |
| `toolPlugins/`   | 声明式插件(新增工具, 免改核心), 见其中示例 |
| 其它自定义目录    | 你自己的知识库, 只要文件头带 TRIGGER 就会被索引 |

## 插件机制(免改核心加工具)
在 `toolPlugins/` 放两个文件即可自动注册:
1. `xxx.json` — `{"name","description","schema","exec":"/绝对路径/xxx.py","admin_only","timeout"}`
2. `xxx.py` — 从 `sys.argv[1]` 读 JSON 参数, `print()` 的内容就是工具返回值
